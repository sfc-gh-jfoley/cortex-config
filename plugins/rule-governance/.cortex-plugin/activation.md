This plugin provides rule and memory governance tools:

- **rule-creator** — Create new rules with proper format and validation
- **rule-reviewer** — Review individual rule quality
- **rule-loader** — Load rules into sessions
- **bulk-rule-reviewer** — Batch review all rules for quality/conflicts
- **memory-organizer** — Organize and deduplicate ctx memories

To enable: `cortex plugin enable rule-governance`

Start with: `$rule-governance:rule-creator` or `$rule-governance:bulk-rule-reviewer`
