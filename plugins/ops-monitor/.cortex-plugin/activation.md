This plugin provides operational monitoring tools:

- **release-change-monitor** — Track Snowflake release changes and new features
- **artifact-drift-monitor** — Detect drift in deployed semantic views, dynamic tables, agents
- **self-healing-pipeline** — Auto-fix broken pipelines with root cause analysis

To enable: `cortex plugin enable ops-monitor`

Start with: `$ops-monitor:release-change-monitor` or `$ops-monitor:artifact-drift-monitor`
