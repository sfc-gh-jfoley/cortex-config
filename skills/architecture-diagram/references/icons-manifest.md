# Icon Manifest

78 hi-res PNG icons available in the `icons/` directory of `excalidraw-prototypes/`.

## Usage in NODE_COLORS

```javascript
{ match: (l) => labelContains(l, "Cortex"), bg: "#ffffff", stroke: PURPLE, icon: "snowflake-cortex.png" },
{ match: (l) => labelContains(l, "Table"), bg: "#ffffff", stroke: GREEN, icon: "ref-table.png" },
{ match: (l) => labelContains(l, "No Icon"), bg: LIGHT_GRAY, stroke: SF_DARK, icon: null },
```
