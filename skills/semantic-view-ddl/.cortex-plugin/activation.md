This plugin provides the **semantic-view-ddl** skill for creating Snowflake Semantic Views using native DDL syntax.

- **semantic-view-ddl** — Create, validate, optimize, and monitor semantic views using `CREATE OR REPLACE SEMANTIC VIEW` DDL

To enable: `cortex plugin enable semantic-view-ddl`

Start with: `$semantic-view-ddl` and describe the tables you want to model.

Triggers: create semantic view DDL, semantic view ddl path, semview ddl, HOL semantic view, auto describe semantic view, SV drift, semantic view health check.
